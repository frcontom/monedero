# WORKFLOW STATES

## Normal

RECEIVED
UNDERSTANDING
ANALYSIS
SOLUTIONS
BACKLOG
PLANNING
READY
CODING
TESTING
VALIDATION
DOCUMENTATION
DONE

## Exceptional

NEEDS_INFORMATION
BLOCKED
REPLANNING
FAILED
CANCELLED

## Valid transitions

RECEIVED -> UNDERSTANDING
UNDERSTANDING -> ANALYSIS
ANALYSIS -> SOLUTIONS
SOLUTIONS -> BACKLOG
BACKLOG -> PLANNING
PLANNING -> READY
READY -> CODING
CODING -> TESTING
TESTING -> VALIDATION
VALIDATION -> DOCUMENTATION
DOCUMENTATION -> DONE

## Recovery transitions

ANALYSIS -> NEEDS_INFORMATION
CODING -> REPLANNING
TESTING -> REPLANNING
REPLANNING -> PLANNING
Any active state -> BLOCKED when a required dependency is unavailable.
